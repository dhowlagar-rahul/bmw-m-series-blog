# BMW M Series Blog

A passion project exploring the legendary BMW M Series lineup. This is a simple web blog built with HTML, CSS, and vanilla JavaScript.

## Live Site
**Check it out here:** [https://dhowlagar-rahul.github.io/bmw-m-series-blog/](https://dhowlagar-rahul.github.io/bmw-m-series-blog/)

## Features
- Clean, responsive design
- Smooth scroll navigation
- Interactive model cards with specs
- Contact form
- Dark theme with modern aesthetics
- Mobile-friendly interface

## Project Structure
```
bmw-m-series-blog/
├── index.html       # Main HTML structure
├── styles.css       # Styling and animations
├── script.js        # Interactive features
└── README.md        # Documentation
```

## Technologies Used
- **HTML5** - Page structure
- **CSS3** - Styling with Flexbox & Grid
- **JavaScript** - DOM manipulation and interactivity
- **GitHub Pages** - Hosting

## What's Inside
- Showcase of BMW M models (M3, M4, M5)
- Performance specifications
- Feature highlights
- Contact form for inquiries

## Getting Started
1. Clone the repo
2. Open `index.html` in your browser
3. Or visit the live version above

## Customization
Feel free to modify:
- Colors in `styles.css`
- Content in `index.html`
- Add more interactive features in `script.js`
